AI سے مفت ویب سائٹ بنانے کا آسان طریقہ یہ ہے کہ آپ Blogger پر نیا blog بنائیں، AI سے Blogger-compatible HTML theme یا page code لکھوائیں، اسے Edit HTML میں paste کریں، پھر Home، About، Contact اور posts کو اپنی ضرورت کے مطابق مکمل کریں۔ Blogger پر Blogspot address کے ساتھ شروع کیا جا سکتا ہے؛ custom domain، paid template یا extra tools الگ خرچ ہو سکتے ہیں۔

یہ گائیڈ اردو اے آئی ماسٹر کلاس کی ویب سائٹ بنانے والی سیریز کا دوسرا حصہ ہے۔ پہلے حصے میں [domain خریدنے اور Blogger سے جوڑنے کا طریقہ](/blog/urdu-ai-master-class-learn-to-create-a-website-without-coding-part-1/) سمجھایا گیا تھا۔ اس حصے میں اصل کام ہے: theme، pages، images، social links اور code errors کو AI کی مدد سے ٹھیک کرنا۔

## قدم 1: Blogger پر site کا مقصد واضح کریں

سب سے پہلے یہ طے کریں کہ ویب سائٹ کس لیے بن رہی ہے۔ مثال کے طور پر:

- ایک teacher کی educational website
- ایک freelancer کی portfolio website
- ایک small business کا service page
- ایک nonprofit یا community project کی information website

Google کی [Blogger Help](https://support.google.com/blogger/answer/1623800?hl=en) کے مطابق نیا blog بنانے کے لیے Blogger میں sign in کریں، New blog پر جائیں، name لکھیں، blog address choose کریں اور save کریں۔ اسی address پر آپ کی basic website publish ہو سکتی ہے۔

## قدم 2: AI کو صاف prompt دیں

AI کو صرف یہ نہ لکھیں کہ "website بنا دو"۔ اسے مقصد، pages، design اور platform واضح بتائیں۔ بہتر prompt یہ ہو سکتا ہے:

```text
Create a responsive HTML theme for a Blogger website.
Website purpose: online education in Urdu.
Pages: Home, About, Contact, Blog.
Style: simple, mobile-friendly, clean navigation.
Include: header, hero section, course cards, footer, WhatsApp link.
Make the code Blogger-compatible.
```

اگر آپ کو prompt writing بہتر سیکھنی ہے تو پہلے [prompt engineering کیا ہے؟](/learn/prompt-engineering/) پڑھیں۔ یہی skill AI سے بہتر code اور بہتر content لینے میں مدد دیتی ہے۔

## قدم 3: Blogger میں HTML paste کرنے سے پہلے backup لیں

Blogger dashboard میں Theme کھولیں، existing theme کا backup download کریں، پھر Edit HTML میں AI کا code paste کریں۔ Backup اس لیے ضروری ہے کہ اگر code خراب ہو جائے تو آپ پرانی theme واپس لگا سکیں۔

یہاں جلدی نہ کریں۔ Code paste کرنے کے بعد preview دیکھیں۔ اگر menu ٹوٹ رہا ہے، mobile screen پر text پھیل رہا ہے، یا images صحیح نہیں آ رہیں تو AI سے ایک ایک مسئلہ fix کروائیں۔

## قدم 4: Home، About اور Contact pages بنائیں

Website صرف خوبصورت theme سے مکمل نہیں ہوتی۔ اسے useful pages کی ضرورت ہوتی ہے:

- Home: آپ کیا کرتے ہیں، کس کے لیے کرتے ہیں، اور reader کو اگلا قدم کیا لینا چاہیے۔
- About: آپ کون ہیں، تجربہ کیا ہے، اور لوگ آپ پر trust کیوں کریں۔
- Contact: email، form، WhatsApp یا social links۔
- Blog posts: وہ useful articles جو search سے visitors لا سکتے ہیں۔

ہر page کے لیے AI سے HTML یا simple Urdu copy لکھوائیں۔ مثال:

```text
Write a simple About page in Urdu for a Pakistani teacher who teaches English online.
Keep it friendly, trustworthy, and mobile-readable.
Return clean HTML for Blogger page editor.
```

## قدم 5: Images، videos اور social links شامل کریں

Blogger post یا page editor میں image upload کریں، پھر جہاں ضرورت ہو image address استعمال کریں۔ About page میں اپنی تصویر، Home page میں service image، اور footer میں YouTube یا Facebook links شامل کیے جا سکتے ہیں۔

اگر آپ YouTube video embed کرنا چاہتے ہیں تو AI سے صرف code نہ بنوائیں؛ پہلے video کا embed code YouTube سے لیں، پھر AI کو کہیں کہ اسے Blogger layout میں صاف طریقے سے fit کرے۔

## قدم 6: Error آئے تو AI سے debug کروائیں

اگر code paste کرنے کے بعد page خراب ہو جائے تو panic نہ کریں۔ Error message، screenshot یا broken section کا code AI کو دیں اور یہ prompt لکھیں:

```text
This Blogger HTML code is breaking the mobile layout.
Fix only the issue, keep the design simple, and return the corrected code.
Explain what changed in 3 bullet points.
```

## قدم 7: Publish کرنے سے پہلے checklist مکمل کریں

Website live کرنے سے پہلے یہ چیزیں لازمی دیکھیں:

- Mobile پر menu صحیح کھل رہا ہے؟
- Home page پر واضح ہے کہ یہ website کس بارے میں ہے؟
- About اور Contact page موجود ہیں؟
- ہر page کا title صاف ہے؟
- Images بہت heavy تو نہیں؟
- Links کام کر رہے ہیں؟
- Privacy یا terms page کی ضرورت ہے؟

اگر website client کے لیے بنا رہے ہیں تو پہلے sample link دکھائیں، feedback لیں، پھر final changes کریں۔ Income کا وعدہ نہ کریں؛ اچھا portfolio، clear service اور مسلسل outreach اصل فرق بناتے ہیں۔

## اکثر پوچھے گئے سوالات

### کیا AI سے مفت ویب سائٹ بن سکتی ہے؟

جی ہاں، Blogger پر Blogspot address کے ساتھ بنیادی ویب سائٹ بنائی جا سکتی ہے۔ لیکن custom domain، paid template یا advanced hosting الگ خرچ ہو سکتے ہیں۔

### Blogger website کے لیے AI سے کیا لکھوائیں؟

AI کو صاف prompt دیں کہ Blogger کے لیے responsive HTML theme چاہیے، pages کون سے ہوں گے، website کس مقصد کے لیے ہے، اور رنگ یا layout کیسا چاہیے۔

### کیا Blogger website بنانے کے لیے coding آنا ضروری ہے؟

Coding آنا ضروری نہیں، لیکن HTML paste کرنے، preview دیکھنے اور error fix کروانے کے لیے basic copy-paste اور instructions سمجھنا ضروری ہے۔

### AI website بنانے کے بعد اگلا قدم کیا ہے؟

Website publish کرنے کے بعد niche، About page، Contact page، privacy page، کم از کم چند useful posts، اور SEO-friendly titles پر کام کریں۔

### اگر AI کا code Blogger میں خراب ہو جائے تو کیا کریں؟

پہلے theme کا backup رکھیں، پھر error message یا screenshot AI کو دیں اور کہیں کہ Blogger HTML کے لیے code fix کرے۔
