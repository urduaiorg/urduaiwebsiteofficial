Prompt engineering کا مطلب AI کو واضح ہدایات دینا ہے تاکہ جواب آپ کے مقصد، audience، tone اور format کے مطابق آئے۔ یہ coding نہیں؛ یہ سوال کو اس طرح لکھنے کی skill ہے کہ ChatGPT، Gemini، Claude یا کوئی اور AI tool آپ کی ضرورت کو زیادہ صاف سمجھ سکے۔

## آسان مثال

فرض کریں آپ ایک درزی سے کپڑے سلوانا چاہتے ہیں۔ اگر آپ صرف کہیں "اچھا suit بنا دیں" تو result آپ کی مرضی سے مختلف ہو سکتا ہے۔ لیکن اگر آپ کہیں "black suit، round neck، sleeves پر light embroidery، office wear کے لیے" تو direction واضح ہو جاتی ہے۔

AI prompt بھی اسی طرح کام کرتا ہے۔ "AI پر مضمون لکھیں" کے بجائے یہ بہتر direction ہے:

```text
پاکستانی college students کے لیے AI literacy پر 300 الفاظ کا Urdu note لکھیں۔ زبان سادہ ہو، examples mobile phone اور WhatsApp سے ہوں، آخر میں 3 practical tips دیں۔
```

## اچھے prompt کی 5 چیزیں

ایک useful prompt میں عموما یہ چیزیں شامل ہوتی ہیں:

- task: AI سے کیا کام چاہیے؟
- audience: جواب کس کے لیے ہے؟
- tone: زبان formal، friendly، teacher-like یا business style؟
- format: bullets، table، paragraph، email، script یا checklist؟
- limits: words، number of points، no hype، no fake facts؟

یہ structure beginners کے لیے کافی ہے۔ Advanced prompt engineering میں examples، source material، role instruction اور evaluation criteria بھی شامل ہو سکتے ہیں۔

## روزمرہ استعمال

Prompt engineering صرف tech لوگوں کے لیے نہیں۔ پاکستان میں ایک teacher lesson plan بنا سکتا ہے، freelancer client proposal بہتر کر سکتا ہے، shop owner WhatsApp product post لکھ سکتا ہے، اور student lecture notes کا خلاصہ لے سکتا ہے۔

مثال:

```text
میں Peshawar میں school teacher ہوں۔ Class 8 کے students کے لیے AI safety پر 20 منٹ کا lesson plan بنائیں۔ زبان آسان Urdu ہو، 3 class activities شامل ہوں، اور آخر میں 5 quiz questions دیں۔
```

## writing tools میں prompt کیسے بدلتا ہے؟

اگر آپ writing کے لیے AI استعمال کر رہے ہیں تو prompt میں اپنی writing کا مقصد ضرور لکھیں۔ صرف "اسے بہتر کریں" کے بجائے کہیں:

```text
اس paragraph کو صاف Urdu میں rewrite کریں۔ meaning نہ بدلیں۔ مشکل الفاظ کم کریں۔ آخر میں بتائیں کہ آپ نے کون سی 3 changes کیں۔
```

Claude کے ساتھ یہی feedback loop بہت کام آتا ہے۔ عملی workflow کے لیے [Claude AI سے اردو writing کیسے کریں؟](/how-to/how-to-use-claude-for-writing/) پڑھیں۔

## image prompts میں کیا فرق ہے؟

Image tools کے prompts میں subject، location، light، mood، composition اور restrictions زیادہ اہم ہوتے ہیں۔ مثال:

```text
Realistic photo of a Pakistani teacher in a small classroom, natural daylight, students listening, warm colors, no text, no watermark.
```

اگر آپ image prompts شروع کر رہے ہیں تو [اپنا AI image generator کیسے بنائیں؟](/blog/how-to-make-your-own-ai-image-generator/) بھی useful next step ہے۔

## عام غلطیاں

صرف topic لکھنا: "AI پر پوسٹ لکھیں"۔

بہت vague tone: "اچھا سا بنا دیں"۔

Fact-check نہ کرنا: AI کے جواب میں names، dates، prices یا claims غلط ہو سکتے ہیں۔

ہر جواب کو final سمجھنا: AI کا پہلا جواب draft ہوتا ہے، publish-ready copy نہیں۔

## اکثر پوچھے گئے سوالات

### Prompt engineering کیا ہے؟

Prompt engineering AI کو ایسی واضح ہدایات دینے کا طریقہ ہے جس میں context، task، audience، tone اور output format پہلے سے بتایا جاتا ہے۔

### اچھے prompt میں کیا شامل ہونا چاہیے؟

ایک اچھے prompt میں کام، قاری، انداز، لمبائی، format، مثال یا پابندیاں شامل ہوتی ہیں۔ صرف topic لکھنے سے اکثر generic جواب آتا ہے۔

### کیا prompt engineering کے لیے coding آنا ضروری ہے؟

نہیں۔ زیادہ تر روزمرہ prompts کے لیے coding ضروری نہیں۔ واضح زبان، مقصد اور follow-up feedback کافی ہوتے ہیں۔

## اگلا قدم

آج ایک prompt اس structure سے لکھیں: task، audience، tone، format، limits۔ پھر AI کے جواب پر ایک follow-up دیں: "اسے زیادہ واضح، مختصر اور پاکستانی context کے قریب بنائیں۔"
