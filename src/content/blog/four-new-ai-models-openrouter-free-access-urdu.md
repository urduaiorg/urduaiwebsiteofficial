ستمبر 2026 کے پہلے ہفتے میں **GPT‑6 Astra، Claude Fable 5.1، Gemini 3.8 Flash اور Meta Muse Spark 1.3** سامنے آئے، مگر چاروں کی رسائی ایک جیسی نہیں۔ 4 ستمبر کو ہماری جانچ کے وقت OpenRouter پر Gemini 3.8 Flash، Claude Fable 5.1 اور Muse Spark 1.3 موجود مگر paid تھے؛ GPT‑6 Astra وہاں درج نہیں تھا۔ OpenRouter مفت AI ضرور دیتا ہے، لیکن اس کا **Free Models Router** ان چاروں کی مفت رسائی کی ضمانت نہیں دیتا۔

یہ فرق اس لیے اہم ہے کہ کسی model کا OpenRouter پر موجود ہونا، اس کا مفت ہونا، اور اس کا کمپنی کی اپنی app میں دستیاب ہونا تین الگ باتیں ہیں۔

## پہلے OpenRouter کو آسان لفظوں میں سمجھیں

OpenRouter ایک مشترک پلیٹ فارم ہے جہاں مختلف کمپنیوں کے سینکڑوں AI models ایک account، chat interface اور API کے ذریعے استعمال کیے جاسکتے ہیں۔ عام صارف بھی اس کے **Chat Playground** میں coding کیے بغیر model منتخب کرکے بات کرسکتا ہے۔

OpenRouter خود کوئی AI model نہیں۔ قیمت، رفتار اور data policy اصل model اور provider کے مطابق بدلتی ہے۔ Paid models کے لیے credits شامل کیے جاتے ہیں اور استعمال کے حساب سے رقم کٹتی ہے؛ ماہانہ subscription ضروری نہیں۔

## چار نئے models میں اصل فرق کیا ہے؟

| ماڈل | بنیادی طاقت | عام رسائی | OpenRouter پر صورتِ حال، 4 ستمبر 2026 |
|---|---|---|---|
| GPT‑6 Astra | computer use، تحقیق، coding اور professional کام | rollout کے ذریعے ChatGPT Plus، Pro، Business اور Enterprise؛ API بھی | ابھی درج نہیں تھا |
| Gemini 3.8 Flash | تیز reasoning، coding اور agent workflows | Google AI Pro/Ultra، Gemini app اور developer tools | موجود؛ 50% introductory discount، مگر مفت نہیں |
| Claude Fable 5.1 | طویل professional، document اور coding projects | Claude Pro، Max، Team، Enterprise اور API | موجود؛ paid |
| Meta Muse Spark 1.3 | coding، tools اور کئی مرحلوں والے agent tasks | Muse Code اور Meta Model API | موجود؛ paid |

ہر model کا مقصد، price اور app مختلف ہے، اس لیے انتخاب اپنے کام کے مطابق کریں، صرف benchmark یا مشہور نام سے نہیں۔

## 1۔ GPT‑6 Astra: جواب سے آگے، کام مکمل کرنے کی کوشش

OpenAI نے GPT‑6 Astra کو computer اور browser استعمال، software engineering، تحقیق، documents، spreadsheets اور presentations جیسے پیچیدہ کاموں کے لیے پیش کیا ہے۔ مقصد ایسا AI ہے جسے صرف سوال کے بجائے پورا کام سونپا جاسکے۔

OpenAI کے مطابق Astra محدود اداروں سے rollout شروع کرکے ChatGPT Plus، Pro، Business اور Enterprise users تک پہنچے گا۔ Free plan اس اعلان میں شامل نہیں۔ API میں اس کی standard قیمت فی دس لاکھ input tokens 10 ڈالر اور output tokens 50 ڈالر ہے۔

OpenRouter کی OpenAI فہرست میں 4 ستمبر کو GPT‑6 Astra موجود نہیں تھا۔ اس لیے ابھی درست راستہ ChatGPT کے اندر rollout یا OpenAI کی اپنی API ہے۔ [GPT‑6 Astra اور AGI، ASI کی مکمل وضاحت یہاں پڑھیں](/blog/gpt-6-astra-is-it-agi-ai-agi-asi-urdu/)۔

## 2۔ Gemini 3.8 Flash: نسبتاً کم قیمت پر مشکل کام

Google کے مطابق Gemini 3.8 Flash کو software engineering، agentic tasks اور کئی مرحلوں والی reasoning میں 3.7 Flash سے بہتر بنایا گیا ہے۔ Flash family رفتار، صلاحیت اور لاگت کے توازن کے لیے بنائی جاتی ہے۔

OpenRouter پر اس کے page پر 50 فیصد introductory discount دکھایا جا رہا ہے۔ بنیادی rate فی دس لاکھ input tokens 0.75 ڈالر اور output tokens 3.75 ڈالر ہے؛ بعض Flex routes کم rate دکھاتے ہیں۔ مگر **discount کا مطلب free نہیں**۔

یہ لمبی PDFs، spreadsheet analysis، coding اور research planning میں مفید ہوسکتا ہے۔ Google AI Pro یا Ultra صارف اسے Gemini app میں بھی آزما سکتے ہیں۔

## 3۔ Claude Fable 5.1: لمبے professional projects کے لیے

Anthropic نے Claude Fable 5.1 کو coding اور knowledge work کے اپنے سب سے capable models میں رکھا ہے۔ یہ کئی گھنٹے چلنے والے projects، بہت سی files اور لمبے professional workflows کے لیے بنایا گیا ہے۔

OpenRouter پر اس کی قیمت فی دس لاکھ input tokens 10 ڈالر اور output tokens 50 ڈالر ہے۔ casual سوال جواب کے لیے یہ مہنگا انتخاب ہوسکتا ہے؛ مشکل codebase، document یا finance analysis میں اس کا فائدہ زیادہ بنتا ہے۔

Claude app میں Fable 5.1، Pro، Max، Team اور Enterprise plans کے لیے دستیاب ہے؛ Free plan شامل نہیں۔ Anthropic کے مطابق safety monitoring کے لیے default data retention 30 دن ہے، اس لیے حساس معلومات سے پہلے policy دیکھیں۔

## 4۔ Meta Muse Spark 1.3: Meta کا agent اور coding model

Muse Spark 1.3 عام WhatsApp، Instagram یا Meta AI chatbot کا نیا نام نہیں۔ Meta نے اسے **Muse Code** اور **Meta Model API** میں جاری کیا ہے۔ اس کی توجہ long-running coding، tools اور کئی مرحلوں والے tasks پر ہے۔

Meta کے مطابق 1.2 کے مقابلے میں نیا model coding tasks میں تقریباً 20 فیصد کم tool calls اور 25 فیصد کم tokens استعمال کرتا ہے۔ یہ کمپنی کا اپنا نتیجہ ہے؛ حقیقی کارکردگی کام کے مطابق بدلے گی۔

OpenRouter پر اس کی قیمت فی دس لاکھ input tokens 1.25 ڈالر اور output tokens 4.25 ڈالر ہے۔ یہ مفت نہیں، مگر developers اسے مشترک API یا agent tool میں آزما سکتے ہیں۔

## پھر OpenRouter کی مفت offer اصل میں کیا ہے؟

OpenRouter کا الگ **Free Models Router** موجود ہے۔ آپ `openrouter/free` منتخب کرتے ہیں اور پلیٹ فارم اپنی موجودہ free فہرست سے ایک مناسب model چنتا ہے۔ model بدل سکتا ہے، اس لیے یہ سیکھنے اور کم استعمال کے لیے اچھا ہے، مگر کسی خاص نئے model کی ضمانت نہیں۔

OpenRouter کی pricing کے مطابق free plan پر اس وقت **50 requests روزانہ** کی حد ہے۔ مفت فہرست بدل سکتی ہے۔ کسی model کے نام کے ساتھ `(free)` یا `:free` نہ ہو تو اسے مفت نہ سمجھیں۔

## OpenRouter پر مفت model استعمال کرنے کا طریقہ

1. [OpenRouter](https://openrouter.ai/) کھولیں اور account بنائیں۔
2. [Chat Playground](https://openrouter.ai/chat) کھولیں۔
3. **Add Model** پر جائیں؛ computer پر `Ctrl+K` یا `Cmd+K` بھی استعمال کیا جاسکتا ہے۔
4. search میں **free** لکھیں۔
5. **Free Models Router** منتخب کریں، یا ایسا مخصوص model چنیں جس کے نام کے ساتھ `(free)` واضح لکھا ہو۔
6. اپنا سوال لکھیں؛ جواب کے ساتھ منتخب model کا نام بھی نظر آسکتا ہے۔

کسی خاص paid model کے لیے exact نام تلاش کریں، موجودہ input/output pricing دیکھیں، credits شامل کریں اور چھوٹے test سے آغاز کریں۔

## عام پاکستانی صارف کے لیے سیدھا مشورہ

روزمرہ سوال، ترجمہ، پڑھائی یا مختصر تحریر کے لیے پہلے موجودہ free ChatGPT، Gemini، Meta AI یا OpenRouter Free Models Router استعمال کریں۔ صرف نئے نام کی وجہ سے paid access نہ لیں۔

اگر آپ developer، researcher یا business team ہیں اور لمبے documents، code یا automation پر کام کرتے ہیں تو OpenRouter تین models کو ایک جگہ test کرنے کا آسان راستہ ہے۔ GPT‑6 Astra کے لیے ابھی OpenAI کا راستہ استعمال کرنا ہوگا۔

اہم اصول: **OpenRouter پر موجودگی کو مفت رسائی نہ سمجھیں۔** model page پر price، free label، provider اور data policy دیکھیں۔ درست انتخاب وہی ہے جو آپ کے کام، budget اور privacy ضرورت کے مطابق ہو۔
