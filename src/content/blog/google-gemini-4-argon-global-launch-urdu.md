گوگل نے **13 اکتوبر 2026** کو اپنا نیا ماڈل جیمینائی 4 آرگن (Gemini 4 Argon) دنیا بھر میں جاری کرنے کا اعلان کیا۔ یہ لمبے اور کئی مرحلوں والے کام، خاص طور پر کوڈنگ، دستاویزات کی جانچ اور تحقیق کے لیے بنایا گیا ہے۔ عام صارفین اسے Gemini app اور Search کے AI Mode میں **Google AI Pro یا Ultra** سبسکرپشن کے ساتھ آزما سکتے ہیں؛ ڈویلپرز کے لیے API کا **paid tier** درکار ہے۔ یہ رسائی آج سے شروع ہو رہی ہے، اس لیے آپ کے اکاؤنٹ میں آپشن ظاہر ہونے کا وقت مختلف ہو سکتا ہے۔ [گوگل کا 13 اکتوبر کا اعلان](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/)

یہ اس ماڈل کی پہلی جھلک نہیں۔ گوگل نے اسے **30 ستمبر** کو محدود شراکت داروں کے لیے متعارف کرایا تھا؛ **13 اکتوبر** کی اصل خبر زیادہ لوگوں کے لیے رول آؤٹ اور استعمال کے راستوں کا اعلان ہے۔

## آرگن میں ایسا کیا ہے جو عام کام سے آگے جاتا ہے؟

گوگل کے مطابق آرگن ایک مسئلے پر کئی مرحلوں تک کام کر سکتا ہے: متعلقہ فائلیں یا دستاویزات پڑھنا، منصوبہ بنانا، اوزار استعمال کرنا، نتیجہ جانچنا اور پھر اگلا قدم لینا۔ مثال کے طور پر بڑے سافٹ ویئر میں ایسی تبدیلی جو سینکڑوں فائلوں پر اثر ڈالتی ہو، یا مختلف دستاویزات سے ایک قابلِ جانچ تجزیہ بنانا۔ یہ صلاحیت ہر کام میں خودکار درستگی کی ضمانت نہیں؛ نتیجہ اور ماخذ انسان کو جانچنے ہوں گے۔

گوگل نے Chrome کے کوڈ میں ایک بڑے اندرونی ریفیکٹر اور اپنے Agent Development Kit کی رفتار بہتر کرنے کی مثالیں دی ہیں۔ کمپنی کے مطابق ADK میں ایک کام کے بعد لمبے سیشن کی تیاری کا وقت **40%** کم ہوا اور پہلی بار import کی رفتار **21%** بڑھی۔ یہ مخصوص منصوبوں کے نتائج ہیں؛ انہیں ہر صارف کے کام پر لاگو نہ سمجھیں۔ [گوگل کی تفصیل](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/#complexengineering)

### ویڈیو: Chrome کے بڑے کوڈ میں تبدیلی

## 1M ٹوکن کی حد کو کیسے سمجھیں؟

گوگل Gemini API میں **1M unified input-output token limit** بتاتا ہے۔ سادہ الفاظ میں، ایک API کام میں ماڈل کو دیا جانے والا مواد اور اس کا جواب ایک مشترک ٹوکن حد کے تحت آتے ہیں۔ **یہ 1M الفاظ نہیں** اور نہ ہی ہر prompt پر اتنا لمبا جواب خودبخود ملتا ہے۔ بڑے جواب اور جاری رہنے والے کام کے لیے گوگل نے developer documentation میں الگ continuation protocol سمجھایا ہے۔ [گوگل کا اعلان](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/#getstarted)، [developer guide](https://aistudio.google.com/docs/long-decode)

عام Gemini app استعمال کرنے والے اس API حد کو اپنے subscription کے روزمرہ استعمال کی حد نہ سمجھیں۔ App کی دستیابی اور usage limits الگ ہو سکتی ہیں۔

## کس کو رسائی مل رہی ہے اور قیمت کیا ہے؟

- **عام صارفین:** Gemini app اور Search کے AI Mode میں Google AI **Pro یا Ultra** سبسکرپشن کے ساتھ رول آؤٹ۔
- **ڈویلپرز:** Gemini API کے **paid tier** میں ماڈل؛ Google AI Ultra رکھنے والے AI Studio اور Antigravity میں بھی آزما سکتے ہیں۔
- **کاروبار:** Google کے enterprise راستوں اور API کے ذریعے رسائی۔
- **سائنس دان:** اہل درخواست دہندگان میں سے **10,000** کو Antigravity کی اعلیٰ usage tier **6 ماہ** کے لیے بغیر قیمت مل سکتی ہے؛ انتخاب، گنجائش اور شرائط لاگو ہیں۔

گوگل نے API کے لیے **30 نومبر 2026** تک ابتدائی قیمت **$2 فی 1M input tokens** اور **$10 فی 1M output tokens** بتائی ہے۔ اس کے بعد اعلان کے مطابق قیمت بالترتیب **$4** اور **$20** ہوگی۔ یہ **API استعمال کی قیمت** ہے، Gemini app کی ماہانہ سبسکرپشن نہیں؛ ٹوکن کے مطابق بل بدلتا ہے۔ قیمت اور پلان خریدنے سے پہلے [گوگل کے موجودہ pricing page](https://aistudio.google.com/docs/pricing) پر دوبارہ دیکھیں۔ [اعلان اور اس کا قیمت والا حاشیہ](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/#footnote-1)، [ڈویلپر اعلان](https://blog.google/innovation-and-ai/technology/developers-tools/build-with-gemini-4-argon/)

گوگل نے **عالمی رول آؤٹ** کہا ہے، مگر ہم نے پاکستان کے ہر اکاؤنٹ یا مقامی ادائیگی کے راستے کی الگ تصدیق نہیں کی۔ اپنے پلان میں دستیابی [Gemini](https://gemini.google.com/) یا [Google AI Studio](https://aistudio.google.com/) کے اندر چیک کریں۔

## تحقیق اور روبوٹکس میں آرگن کیا دکھا رہا ہے؟

گوگل ڈیپ مائنڈ کے ایک **اندرونی ٹیسٹ** میں آرگن نے ایک انسان کے کھیلنے کی ویڈیو دیکھ کر humanoid robot کے لیے simulation code تیار کیا۔ کمپنی کے مطابق Apptronik کے Apollo robot نے حقیقی تجربے میں مسلسل **7** درست throws کیے۔ اس سے ماڈل کی تحقیقاتی سمت سمجھ آتی ہے؛ اسے عام صارف کے لیے دستیاب robot feature یا آزادانہ تصدیق شدہ معیار نہ سمجھیں۔ [گوگل کا بیان](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/#realworldimpact)

## آج اسے آزمانے کا درست طریقہ کیا ہے؟

اگر آپ کے پاس **Google AI Pro یا Ultra** ہے تو [Gemini app](https://gemini.google.com/) کھول کر ماڈل کی فہرست میں Argon دیکھیں۔ آپشن نہ آئے تو رول آؤٹ، اکاؤنٹ اور علاقے کی شرائط چیک کریں۔ ایک حقیقی مگر کم خطرے والا کام دیں، مثلاً اپنی ہی دستاویزات سے سوالات کی فہرست یا اپنے codebase کے کسی حصے کا جائزہ۔ پہلے چھوٹے کام پر نتیجہ اور ماخذ دیکھیں؛ پھر اسے زیادہ پیچیدہ کام میں استعمال کریں۔

اگر آپ developer ہیں تو [Gemini API guide](https://aistudio.google.com/learn/gemini-4-argon-developer-guide) میں ماڈل، setup اور لمبے جواب کی شرط دیکھیں۔ API کی قیمت اور token استعمال پر نظر رکھیں۔ حساس معلومات یا خودکار بیرونی کارروائی کے لیے اپنی منظوری اور انسانی review کا مرحلہ رکھیں۔

**اصل فرق** یہ ہے کہ Argon اب محدود preview سے وسیع rollout میں آ رہا ہے۔ ویڈیوز اس کی ممکنہ صلاحیت دکھاتی ہیں؛ آپ کے کام میں اس کی قدر کا فیصلہ اپنے مواد، خرچ اور جانچے ہوئے نتیجے سے ہوگا۔
