28 جولائی 2026 کو Meta نے اعلان کیا کہ **WhatsApp Web** میں براہِ راست one-to-one اور group audio/video calls شامل کی جا رہی ہیں۔ یعنی جب یہ سہولت آپ کے account میں آ جائے تو browser سے واٹس ایپ کھول کر الگ app download کیے بغیر کال کی جا سکے گی۔ اس کے ساتھ جاری group call کو ایک device سے دوسرے device پر منتقل کرنے، call-link کے لیے waiting room، QuickHD video اور background noise suppression جیسی خصوصیات بھی متعارف ہو رہی ہیں۔

یہ اعلان ان لوگوں کے لیے خاص طور پر مفید ہے جو دفتر، یونیورسٹی یا گھر میں laptop پر زیادہ کام کرتے ہیں۔ اب chat دیکھتے ہوئے فون ڈھونڈنے یا meeting کے لیے الگ platform کھولنے کی ضرورت کم ہو سکتی ہے۔ البتہ Meta نے واضح کیا ہے کہ یہ features **مرحلہ وار** آ رہے ہیں؛ اس لیے اسے فوری طور پر پاکستان سمیت ہر جگہ ہر user کے لیے فعال سمجھنا درست نہیں ہو گا۔

## WhatsApp Web calling کیا ہے؟

WhatsApp Web وہ browser-based version ہے جسے آپ computer پر کھولتے ہیں۔ نئی تبدیلی کے بعد browser کے اندر ہی آڈیو اور ویڈیو کال کی جا سکے گی۔ [Meta کے آفیشل اعلان](https://about.fb.com/news/2026/07/whatsapp-web-calling-new-features/) کے مطابق یہ one-to-one calls کے ساتھ group calls کے لیے بھی دستیاب ہو گی اور اس کے لیے separate app download کی شرط نہیں رکھی گئی۔

Web version میں ایک الگ **Calls tab** بھی شامل ہو رہا ہے، جہاں browser سے call history اور favourites دیکھے جا سکیں گے۔ Meta کے مطابق screen sharing اور reactions بھی Web calls کا حصہ ہوں گے۔ اس کا مطلب یہ نہیں کہ WhatsApp، Zoom یا کسی مکمل webinar platform کا ہر متبادل بن گیا ہے؛ مگر روزمرہ team discussion، کلاس project یا خاندان کی گروپ کال کے لیے browser سے کام شروع کرنا آسان ہو سکتا ہے۔

## Call transfer: جاری group call کو device بدل کر جاری رکھیں

اس اپڈیٹ کی سب سے کارآمد سہولت **call transfer** ہے۔ اگر آپ mobile یا tablet پر group call میں ہیں اور پھر computer پر کام شروع کرنا چاہتے ہیں تو Meta کے مطابق call ختم کیے بغیر اسے WhatsApp Web یا WhatsApp Desktop پر منتقل کیا جا سکے گا۔ اسی طرح computer سے واپس دوسرے device پر جانا بھی ممکن ہو گا۔

یہ feature ان حالات میں معنی رکھتا ہے جہاں آپ کو screen share دیکھنی ہو، keyboard سے notes لینے ہوں، یا فون کی battery کم ہو رہی ہو۔ اہم بات یہ ہے کہ Meta نے اسے **active group calls** کے لیے بیان کیا ہے؛ اس اعلان کی بنیاد پر ہر قسم کی individual call یا ہر device scenario کے بارے میں اضافی دعویٰ نہیں کرنا چاہیے۔

## Waiting room: call link پر بہتر control

Group call link بناتے وقت اب **“Require approval to join”** کا option ملے گا۔ اسے فعال کرنے پر link کھولنے والا شخص فوراً call میں شامل نہیں ہو گا؛ وہ waiting room میں رہے گا، اور call میں موجود کوئی participant اسے approve یا deny کر سکے گا۔

یہ چھوٹی مگر مفید تبدیلی ہے۔ مثلاً class group، office team یا community meeting میں link غلط chat میں forward ہو جائے تو میزبان کے پاس آنے والوں کو دیکھ کر شامل کرنے کا اختیار موجود رہے گا۔ یہ privacy کا مکمل متبادل نہیں: link صرف قابلِ اعتماد لوگوں کے ساتھ ہی share کرنا چاہیے، اور حساس گفتگو کے لیے participants کو پہلے verify کرنا بہتر عادت ہے۔

## QuickHD اور noise suppression کیا بدلیں گے؟

Meta کے مطابق **QuickHD** کال کے ابتدائی seconds میں ہی HD video فراہم کرنے کے لیے بنایا گیا ہے، تاکہ گفتگو کے شروع میں تصویر کم واضح ہونے کا انتظار نہ کرنا پڑے۔ جبکہ **background noise suppression** in-call settings سے فعال کیا جا سکے گا، جس کا مقصد اردگرد کے غیر ضروری شور کو کم کرنا ہے۔

ان دونوں خصوصیات کا نتیجہ internet connection، browser، microphone اور device کی صلاحیت پر مختلف ہو سکتا ہے۔ اس لیے QuickHD کو ہر نیٹ ورک پر لازماً ایک جیسا flawless نتیجہ دینے کا وعدہ نہ سمجھیں۔ زیادہ درست بات یہ ہے کہ واٹس ایپ نے بہتر آغازِ ویڈیو اور کم background noise کے لیے یہ controls متعارف کرانے کا اعلان کیا ہے۔

## رازداری: Meta نے کیا کہا ہے؟

Meta کا کہنا ہے کہ WhatsApp Web calls **end-to-end encrypted** ہوں گی اور ان پر time limit یا fee نہیں ہو گی۔ end-to-end encryption سے مراد یہ ہے کہ call کا مواد صرف اس میں شامل لوگوں کے devices کے درمیان محفوظ رہنے کے لیے بنایا جاتا ہے، نہ کہ عام طور پر platform کو سننے یا دیکھنے کے لیے۔

پھر بھی عملی احتیاط ضروری ہے: shared computer پر WhatsApp Web کھلا نہ چھوڑیں، کام ختم ہونے پر log out کریں، اور کسی مشکوک call link سے join کرنے سے پہلے chat اور participants کو دیکھ لیں۔ encryption کال کے مواد کی حفاظت سے متعلق ہے؛ یہ غلط link، غیر محفوظ computer یا کسی کے screen recording کرنے کے ہر خطرے کو خود بخود ختم نہیں کرتی۔

## آپ کے لیے اس کا عملی مطلب

جب یہ update آپ کے account میں نظر آئے تو WhatsApp Web کے Calls tab میں جا کر contact یا group کے لیے audio یا video call کا option دیکھیں۔ اگر آپ call link بناتے ہیں تو صرف قابلِ اعتماد افراد کو بھیجیں اور جہاں مناسب ہو **Require approval to join** استعمال کریں۔ جاری group call میں device بدلنے کی ضرورت پڑے تو call transfer آزمایا جا سکتا ہے۔

سب سے اہم بات: ابھی rollout جاری ہے۔ اگر option نظر نہ آئے تو اسے کسی خرابی یا region-specific محرومی کا ثبوت نہ سمجھیں۔ Meta نے صرف اتنا کہا ہے کہ features بتدریج جاری کیے جا رہے ہیں اور جلد سب کے لیے دستیاب ہوں گے۔

**سادہ بات:** واٹس ایپ اب browser کو محض chat window سے آگے لے جا رہا ہے۔ Web calling، device transfer اور waiting room روزمرہ گفتگو کو زیادہ flexible بنا سکتے ہیں—بشرطیکہ آپ availability، privacy اور call links کو سمجھ داری سے استعمال کریں۔
