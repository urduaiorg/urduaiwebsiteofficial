# مفت چیٹ جی پی ٹی اب خود کام کرے گا—Scheduled Tasks کیسے استعمال کریں؟

**اوپن اے آئی (OpenAI) نے 25 اگست 2026 کو چیٹ جی پی ٹی (ChatGPT) کے Scheduled Tasks مفت صارفین تک بڑھا دیے۔ Eligible Free اور Go صارفین اب تین active tasks بنا سکتے ہیں جو ایک دفعہ یا روزانہ، ہفتہ وار اور دوسرے مقررہ وقفوں پر خود چلیں، پھر نتیجہ push notification یا email کے ذریعے پہنچائیں۔** اس کا مطلب یہ ہے کہ آپ کو ایک ہی ہدایت بار بار لکھنے کی ضرورت نہیں، لیکن مفت پلان میں exact time اور hourly automation دستیاب نہیں۔

## Scheduled Task اصل میں کیا کرتا ہے؟

Scheduled Task ایسی محفوظ ہدایت ہے جسے چیٹ جی پی ٹی آپ کے مقرر کردہ دن یا وقفے پر دوبارہ چلاتا ہے۔ مثال کے طور پر آپ اسے کہہ سکتے ہیں کہ ہر صبح پانچ نئے English words سکھائے، ہر اتوار اگلے ہفتے کا study plan بنائے یا ہر شام آپ سے دن کے اہم کاموں کا جائزہ لینے کو کہے۔

عام chat میں جواب اسی وقت آتا ہے جب آپ سوال بھیجتے ہیں۔ Scheduled Task میں آپ پہلے سے وقت یا معمول طے کرتے ہیں۔ وقت آنے پر چیٹ جی پی ٹی task چلاتا ہے اور supported device پر اطلاع بھیج سکتا ہے۔

یہ مکمل انسانی assistant نہیں جو ہر website یا account میں خود فیصلہ کرکے کام کرتا رہے۔ مفت صارف کے لیے اس کا سب سے قابلِ اعتماد استعمال یاد دہانی، باقاعدہ مشق، routine planning اور بار بار بننے والے مختصر مواد میں ہے۔

## مفت اور paid plans میں کیا فرق ہے؟

اوپن اے آئی کی 26 اگست 2026 کو اپڈیٹ کی گئی documentation کے مطابق بنیادی limits یہ ہیں:

| پلان | Active tasks | کتنی بار چل سکتا ہے؟ |
|---|---:|---|
| Free اور Go | 3 | ایک دفعہ یا زیادہ سے زیادہ روزانہ؛ flexible time window |
| Plus | 5 | exact time اور گھنٹہ وار schedule کی سہولت ہوسکتی ہے |
| Pro | 15 | زیادہ task capacity اور eligible paid scheduling |

Free users کو morning، afternoon یا night جیسی flexible window ملتی ہے۔ اگر آپ کہیں کہ “روزانہ صبح یہ کام کرو” تو نتیجہ اس window کے اندر آسکتا ہے؛ بالکل آٹھ بجے آنے کی ضمانت نہیں۔ اسی لیے دوا، flight، امتحان کی آخری deadline یا کسی دوسرے حساس کام کے لیے اسے واحد reminder نہ بنائیں۔

Plan limits کے علاوہ model، workspace اور app settings بھی اثر انداز ہوسکتی ہیں۔ اگر Scheduled option نظر نہ آئے تو ChatGPT کا web version کھولیں اور اپنی app کو تازہ ترین version پر update کریں۔ اوپن اے آئی نے پاکستان کے لیے الگ rollout وعدہ نہیں کیا؛ آفیشل documentation صرف یہ کہتی ہے کہ availability account، app اور app version کے مطابق مختلف ہوسکتی ہے۔

## اپنا پہلا task کیسے بنائیں؟

چیٹ جی پی ٹی کھول کر **Scheduled** پر جائیں۔ اگر یہ option آپ کے account میں موجود ہو تو نئی ہدایت لکھیں، دن یا وقفہ منتخب کریں اور task محفوظ کردیں۔ آپ عام chat میں بھی واضح schedule کے ساتھ کام لکھ سکتے ہیں، مثلاً:

> ہر صبح مجھے روزمرہ گفتگو میں استعمال ہونے والے پانچ نئے English words سکھائیں۔ ہر لفظ کا آسان اردو مطلب، ایک مثال اور آخر میں تین سوالوں کا مختصر quiz دیں۔

Task بننے کے بعد چیٹ جی پی ٹی confirmation دکھاتا ہے۔ Notifications کے لیے **Settings → Notifications** میں Push، Email یا دونوں منتخب کیے جاسکتے ہیں۔ اسی جگہ **Manage tasks** کھول کر task کو edit، pause یا delete کیا جاسکتا ہے۔

موبائل پر push notification حاصل کرنے کے لیے ChatGPT app کو notification permission دینا ضروری ہے۔ اگر permission بند ہو تو task چل سکتا ہے، لیکن آپ کو بروقت اطلاع نظر نہ آئے۔

## مفت صارف کے لیے تین مفید tasks کون سے ہیں؟

Free plan میں صرف تین active slots ہیں، اس لیے ایسے کام منتخب کریں جو واقعی بار بار کرنے پڑتے ہیں۔ یہ مثالیں کسی external account یا حساس data کے بغیر چل سکتی ہیں۔

### روزانہ سیکھنے کا task

> ہر شام مجھے مصنوعی ذہانت کا ایک بنیادی تصور سادہ اردو میں سمجھائیں۔ ایک روزمرہ مثال دیں، پھر دو سوالوں سے میرا علم جانچیں۔ پچھلے دن کی بات نہ دہرائیں۔

یہ طالب علم، استاد یا AI سیکھنے والے beginner کے لیے مسلسل چھوٹی مشق بن سکتا ہے۔ جواب درست سمجھنے کے بعد اہم facts کو اصل source سے verify کرنا پھر بھی ضروری ہے۔

### امتحان کی مختصر مشق

> ہر پیر، بدھ اور ہفتہ دوپہر جماعت دہم کے Biology موضوع [موضوع لکھیں] سے پانچ MCQs دیں۔ پہلے میرے answers لیں، پھر درست جواب اور مختصر وجہ بتائیں۔

اپنی کتاب یا board syllabus کے مطابق topic ضرور دیں۔ چیٹ جی پی ٹی سوال بنانے میں مدد دے سکتا ہے، لیکن اسے امتحانی board کی آفیشل marking scheme نہ سمجھیں۔

### ہفتہ وار کاروباری content plan

> ہر اتوار میرے چھوٹے کاروبار [کاروبار کی قسم] کے لیے اگلے ہفتے کی تین Facebook posts کا plan بنائیں۔ ہر post میں ایک حقیقی customer problem، سادہ حل اور مختصر call to action ہو۔ قیمت یا discount خود سے نہ بنائیں۔

یہ task ideas کا پہلا draft دے گا۔ کاروبار کا مالک قیمت، stock، offer اور مقامی context خود check کرکے ہی post شائع کرے۔

اساتذہ اسی pattern سے weekly lesson outline، job seekers interview practice اور گھر کے افراد meal-planning checklist بنا سکتے ہیں۔ البتہ task instructions میں شناختی دستاویز، bank details، password، medical record یا دوسرا حساس data شامل نہ کریں۔

## کسی task کو دوسرے شخص کے ساتھ کیسے بانٹیں؟

OpenAI نے task sharing بھی شامل کی ہے۔ Scheduled page میں task کے تین نقطوں والے menu سے **Share** منتخب کریں، instructions کا جائزہ لیں اور link copy کردیں۔ Link کھولنے والا شخص task کو دیکھ کر اپنے account میں اس کی الگ copy بناتا ہے؛ آپ کا اصل task اس کے account میں منتقل نہیں ہوتا۔

Shared link میں task کا title، instructions، schedule اور original time zone نظر آسکتا ہے۔ لیکن creator کا نام، chat history، پرانے results، memories، attached files، connected-app data اور login credentials شامل نہیں ہوتے۔ پھر بھی personal-account link رکھنے والا ہر شخص task instructions پڑھ سکتا ہے، اس لیے title یا prompt میں نجی معلومات نہ لکھیں۔

اصل task میں بعد کی تبدیلی shared copy میں خودکار طور پر نہیں جاتی۔ اگر آپ instructions بدلیں تو updated link دوبارہ share کرنا ہوگا۔

## Paid users کو Gmail اور websites کے ساتھ کیا اضافی سہولت ملی؟

Plus اور Pro کے eligible صارفین ChatGPT Work میں Gmail، Slack یا GitHub activity سے چلنے والے event-triggered tasks بنا سکتے ہیں۔ مثال کے طور پر کسی مخصوص Gmail message کے آنے پر summary تیار کرنا، Slack feedback سے next steps لکھنا یا GitHub pull request بدلنے پر review task چلانا۔ Free اور Go accounts یہ webhook-based tasks نہیں بنا سکتے۔

اسی update میں ChatGPT Work کا browser بعض signed-in websites پر task جاری رکھ سکتا ہے۔ Login screen آنے پر صارف اپنی credentials خود داخل کرتا ہے؛ OpenAI کے مطابق model username یا password نہیں دیکھتا۔ Reservation، payment یا دوسرے consequential action سے پہلے confirmation مانگی جاتی ہے۔ Website authentication فی الحال Plus اور Pro plans کے لیے ہے، اس لیے اسے مفت Scheduled Tasks کے ساتھ نہ ملائیں۔

## یہ کن کاموں کے لیے مناسب نہیں؟

Scheduled Tasks ابھی Voice chats اور custom GPTs کے ساتھ کام نہیں کرتے۔ Project کے اندر بنایا گیا task اس project کی uploaded یا stored files تک رسائی بھی نہیں رکھتا۔ Exact-time alerts، مسلسل monitoring اور connected apps plan اور permissions پر منحصر ہیں۔

یہ بھی یاد رکھیں کہ scheduled ہونے سے جواب لازماً درست نہیں ہوجاتا۔ AI غلط fact، پرانی معلومات یا کمزور suggestion دے سکتا ہے۔ اہم خبر، scholarship deadline، مالی فیصلہ، طبی ہدایت یا آفیشل اعلان ہمیشہ اصل source پر کھول کر دیکھیں۔

مفت صارف کے لیے اصل فائدہ سادہ ہے: چیٹ جی پی ٹی اب صرف آپ کے سوال کا فوری جواب نہیں دیتا، بلکہ تین منتخب routines کو خود یاد رکھ کر مقررہ وقفے پر چلا سکتا ہے۔ تین slots کو معمولی reminders سے بھرنے کے بجائے ایک learning task، ایک planning task اور ایک ایسا repeatable کام دیں جو ہر ہفتے آپ کا وقت بچائے۔
