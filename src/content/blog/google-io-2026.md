# گوگل I/O 2026: دس بڑے اعلانات — پاکستانیوں کے لیے مکمل گائیڈ

گوگل نے ۱۹ مئی ۲۰۲۶ کو Google I/O میں دس بڑے اعلانات کیے جن کا مرکزی خیال ایک ہے: اے آئی کو چیٹ بوٹ سے نکال کر ہر ایپ میں ایک کام کرنے والے ایجنٹ میں بدلنا۔ جیمینی 3.5 فلیش سے Docs Live تک — یہ سب آج سے شروع ہو رہا ہے، کچھ مفت، کچھ پیڈ، کچھ ابھی صرف امریکہ میں۔

## ۱. جیمینی 3.5

گوگل کی نئی ماڈل فیملی جو سرحدی ذہانت کو عمل کے ساتھ جوڑتی ہے۔ **جیمینائی 3.5 Flash** آج سے جیمینی ایپ کا ڈیفالٹ ماڈل ہے — پرانے 3.1 Pro سے کوڈنگ اور ایجنٹک کاموں میں بہتر، چار گنا تیز۔ **جیمینائی 3.5 Pro** اگلے مہینے آئے گا۔

## ۲. جیمینی اسپارک

چوبیس گھنٹے چلنے والا ذاتی اے آئی ایجنٹ جو آپ کی Gmail، Docs اور دیگر ایپس میں پس پردہ کام کرتا رہتا ہے — فون بند ہو تب بھی۔ بار بار آنے والے کام خود ترتیب دیتا ہے، پیچیدہ ورک فلو بناتا ہے، اور نئی مہارتیں سیکھتا ہے۔ جیمینی ایپ میں بطور بیٹا آ رہا ہے۔

## ۳. جیمینی اومنی

ایک نیا ورلڈ ماڈل جو تصویر، آڈیو، ویڈیو اور متن — سب کو بیک وقت سمجھ کر ہائی کوالٹی ویڈیو بناتا ہے۔ Google Flow، جیمینی ایپ اور یوٹیوب پر دستیاب ہے۔ یوٹیوبرز اور کانٹینٹ کریٹرز کے لیے یہ سب سے اہم اپ گریڈ ہے۔

## ۴. Antigravity اور جنریٹو UI

گوگل سرچ اب صرف لنکس نہیں دیتی — Antigravity کی بدولت آپ کے سوال کے جواب میں سرچ خود ایک انٹریکٹو ڈیش بورڈ، ٹریکر یا سمولیشن بنا دیتی ہے، موقع پر، بغیر کسی ایپ کے۔ مثلاً: "فٹنس ٹریکر بناؤ" لکھیں اور سرچ ایک مکمل UI بنا کر دے گی۔

## ۵. Daily Brief

صبح اٹھتے ہی جیمینی ایپ آپ کے دن کا ذاتی خلاصہ تیار رکھتی ہے — رات کی ای میلز کا جائزہ، آج کے کام، اگلا قدم۔ بھاگ دوڑ ختم، منصوبہ شروع۔

## ۶. Docs Live

گوگل Docs میں اب آواز سے دستاویز بنائیں۔ بولتے جائیں — Docs Live خاکہ بنائے گا، لہجہ درست کرے گا اور پہلا مسودہ تیار کرے گا۔ طلبہ، اساتذہ اور فری لانسرز کے لیے خاص طور پر مفید۔

## ۷. Google Flow اور اے آئی Studio

**Google Flow** — گوگل کا کریٹو اسٹوڈیو — جیمینی اومنی کے ساتھ مکمل طور پر اپ گریڈ ہوا۔ اب ایک ہی جگہ سے ویڈیو بنانا، ایڈٹ کرنا اور موسیقی تیار کرنا ممکن ہے۔ **گوگل اے آئی اسٹوڈیو (Google AI Studio)** میں اب پرامٹ لکھ کر پورا اینڈرائیڈ ایپ بنائیں، ایمولیٹر میں ٹیسٹ کریں، اور براہ راست Play Store پر پبلش کریں — مفت۔

## ۸. Universal Cart

گوگل پر ایک ذہین شاپنگ کارٹ جو کئی دکانوں کا سامان ایک جگہ اکٹھا کرتی ہے۔ ابھی امریکہ میں۔

## ۹. Neural Expressive — جیمینی ایپ کا نیا ڈیزائن

جیمینی ایپ مکمل نئے ڈیزائن کے ساتھ آئی ہے — نئے رنگ، روانی کے ساتھ اینیمیشن، اور جیمینائی Live سے آسان سوئچنگ۔ وہی جیمینی، بالکل نئے انداز میں۔

## ۱۰. C2PA اور SynthID

گوگل نے اے آئی سے بنا مواد پہچاننے کی صلاحیت بڑھا دی۔ SynthID کے ساتھ اب C2PA کنٹینٹ کریڈینشلز بھی شامل ہیں — سرچ، جیمینی ایپ اور دیگر پلیٹ فارمز پر آپ دیکھ سکیں گے کہ کوئی تصویر یا ویڈیو اصل ہے یا اے آئی سے بنی ہے۔

## پاکستان کے لیے کیا مطلب ہے؟

**ابھی مفت، پاکستان میں کام کرتا ہے:**
جیمینی 3.5 فلیش — gemini.google.com پر آج سے۔
گوگل اے آئی اسٹوڈیو — aistudio.google.com، ایپ بلڈر سمیت، مفت۔
Docs Live — Google Docs میں Workspace صارفین کے لیے آ رہا ہے۔

**ابھی محدود یا پیڈ:**
جیمینی اسپارک، Daily Brief — ابھی صرف امریکہ میں، اے آئی Ultra سبسکرپشن درکار جو USD میں مہنگی ہے۔
Google Flow کے نئے فیچرز، Universal Cart — مرحلہ وار رول آؤٹ، پاکستان میں وقت لگے گا۔

ایک اہم بات: Docs Live آواز سے دستاویز بنانے کا ٹول ہے — یہ اردو میں کتنا کام کرے گا اس کا ابھی تجربہ کرنا باقی ہے۔ ہم آزما کر بتائیں گے۔

## اکثر پوچھے جانے والے سوالات

**جیمینی 3.5 فلیش پاکستان میں مفت ہے؟**
ہاں۔ gemini.google.com یا جیمینی اینڈرائیڈ ایپ پر آج سے مفت دستیاب ہے۔

**جیمینی اسپارک اور Daily Brief کب پاکستان آئیں گے؟**
ابھی صرف امریکہ میں اور اے آئی Ultra سبسکرپشن کے ساتھ — پاکستان میں تاریخ واضح نہیں۔ انتظار کریں۔

**Docs Live کیا ہے اور کیسے کام کرتا ہے؟**
گوگل Docs میں آواز سے دستاویز بنانے کا نیا فیچر ہے۔ بولتے جائیں، Docs Live خاکہ اور مسودہ خود بناتا ہے۔ Workspace صارفین کے لیے جلد آ رہا ہے۔

**گوگل اے آئی اسٹوڈیو سے ایپ کیسے بنائیں؟**
aistudio.google.com پر جائیں، اپنی ایپ کا خیال لکھیں، اے آئی باقی کام کرے گا — کوڈ، ایمولیٹر ٹیسٹ اور Play Store پبلشنگ تک۔ مفت ہے۔

> یاد رکھیں: جیمینی 3.5 فلیش اور اے آئی Studio — یہ دو چیزیں ابھی پاکستان میں مفت اور قابل استعمال ہیں۔ باقی بڑے اعلانات یا USD میں مہنگے ہیں یا ابھی پاکستان نہیں پہنچے۔

گوگل نے I/O 2026 میں ایک واضح پیغام دیا: جیمینی صرف ایک ایپ نہیں رہا — یہ ہر گوگل پروڈکٹ کی پرت بن گیا ہے۔ آپ جو بھی گوگل ٹول استعمال کرتے ہیں، اگلے چھ ماہ میں وہ مختلف ہوگا۔
