ChatGPT Sites میں website بنانے کا طریقہ یہ ہے کہ پہلے site کا مقصد اور visitor کے actions واضح لکھیں، پھر ChatGPT Work میں `@Sites` کے ساتھ prompt دیں، preview میں تبدیلیاں کرائیں اور آخر میں Share controls سے طے کریں کہ اسے کون دیکھ سکتا ہے۔ یہ feature coding کے بغیر hosted website، dashboard، interactive tool یا سادہ web app بنانے میں مدد دیتا ہے، لیکن public کرنے سے پہلے content اور permissions کی انسانی جانچ ضروری ہے۔

## Website شروع کرنے سے پہلے کیا طے کریں؟

اچھا نتیجہ “میرے لیے website بنا دو” سے نہیں، واضح brief سے نکلتا ہے۔ پہلے چار سوالوں کے جواب لکھ لیں:

- website کس کے لیے ہے؟
- visitor یہاں کون سا کام کرے گا؟
- کون سے pages یا حصے ضروری ہیں؟
- کون سی معلومات محفوظ یا upload ہوں گی؟

مثلاً کسی اسکول کے event page کے لیے صرف خوب صورت homepage کافی نہیں۔ والدین کو تاریخ، مقام، schedule، registration اور contact information بھی چاہیے۔ اگر یہ بات prompt میں پہلے لکھ دی جائے تو پہلی draft زیادہ مفید ہوگی۔

## ChatGPT Sites میں پہلا prompt کیسے دیں؟

نئی Work conversation شروع کریں یا اس chat کو کھولیں جہاں آپ پہلے ہی منصوبہ بنا چکے ہیں۔ پھر `@Sites` لکھ کر outcome بیان کریں۔

> @Sites ہمارے اسکول کے سالانہ Science Fair کے لیے mobile-friendly website بنائیں۔ homepage پر event کا نام، تاریخ، مقام اور مختصر تعارف ہو۔ الگ sections میں schedule، طلبہ کے projects، والدین کے لیے ہدایات، registration form اور contact information شامل کریں۔ رنگ نیوی بلیو اور سنہری رکھیں۔ کوئی payment یا public student data شامل نہ کریں۔

پہلے سے موجود conversation استعمال کرنے کا فائدہ یہ ہے کہ dates، notes اور فیصلے دوبارہ لکھنے کی ضرورت کم ہو جاتی ہے۔ لیکن prompt میں یہ ضرور بتائیں کہ کون سی معلومات site پر دکھانی ہیں اور کون سی صرف planning تک محدود رہیں گی۔

## ChatGPT کس قسم کی site بنا سکتا ہے؟

ایک simple information page کے علاوہ Sites storefront demo، data explorer، game اور team dashboard جیسے تجربات بھی بنا سکتا ہے۔ site form responses، votes یا expenses جیسے records database میں محفوظ کر سکتی ہے، اور receipts، photos یا documents upload کرنے کی جگہ بھی بنائی جا سکتی ہے۔

![ChatGPT Sites سے بنائی گئی Event Planning Hub کی مثال](/images/guides/chatgpt-work-shareable-site/step-02-event-planning-site.jpg)

*یہ OpenAI کا Event Planning Hub example ہے: dashboard میں requests، upcoming events، approvals اور templates ایک جگہ دکھائے گئے ہیں۔*

یہ capabilities ہر project میں لازماً شامل نہ کریں۔ ایک freelancer کا portfolio صرف services، work samples اور contact form سے بہتر ہو سکتا ہے؛ غیر ضروری login، database یا file upload site کو پیچیدہ بنا دے گا۔

## Preview میں تبدیلی کیسے کرائیں؟

پہلی draft کو final نہ سمجھیں۔ یہ ترتیب اپنائیں:

1. headline، dates، names، prices اور contact details پڑھیں؛
2. ہر button اور link کھول کر دیکھیں؛
3. mobile preview میں text اور forms آزمائیں؛
4. صرف ایک تبدیلی فی instruction لکھیں تاکہ نتیجہ واضح رہے۔

ChatGPT desktop app میں site کو in-app Browser میں کھولیں، جس حصے کو بدلنا ہو وہاں comment چھوڑیں اور اسی conversation میں تبدیلی کہیں۔ web پر preview کھول کر **Edit** منتخب کریں اور ہدایت لکھیں۔

> Registration form کو schedule کے فوراً بعد لے آئیں۔ form میں صرف طالب علم کا نام، جماعت اور والدین کا phone number رکھیں۔ submit ہونے کے بعد اردو میں confirmation message دکھائیں۔ باقی layout تبدیل نہ کریں۔

## Site کو کس کے ساتھ Share کریں؟

نئی site پہلے owner اور workspace admins تک محدود رہتی ہے۔ review مکمل ہونے کے بعد Sites dashboard میں project تلاش کریں اور **Share** منتخب کریں۔ دستیاب options account اور workspace settings کے مطابق بدل سکتے ہیں:

- **Owner and workspace admins:** draft کی جانچ کے لیے؛
- **Selected people or groups:** چند ساتھیوں یا clients کے لیے؛
- **Anyone in your workspace:** پوری organization کے لیے؛
- **Anyone on the internet:** public audience کے لیے، اگر public publishing فعال ہو۔

![ChatGPT Sites dashboard میں Share controls](/images/guides/chatgpt-work-shareable-site/step-03-sites-sharing-controls.jpg)

*بائیں طرف Sites منتخب ہے، درمیان میں projects ہیں اور ہر row کے ساتھ Share control موجود ہے۔*

Public link دینے سے پہلے ایک بار private access پر site کھولیں۔ پھر کسی دوسرے device پر link آزمائیں تاکہ پتا چل سکے کہ visitor وہی دیکھ رہا ہے جو آپ چاہتے ہیں۔

## پاکستانی قارئین کے لیے تین تیار prompts

### چھوٹے کاروبار کا catalog

> @Sites میرے چھوٹے کاروبار [نام] کے لیے mobile-friendly product catalog بنائیں۔ categories، product cards، قیمت، دستیابی اور WhatsApp inquiry button شامل کریں۔ یہ demo catalog ہوگا؛ checkout یا payment نہ بنائیں۔ اردو اور English دونوں میں مختصر product descriptions دکھائیں اور ہر قیمت کو review کے لیے واضح نشان زد کریں۔

### Freelancer portfolio

> @Sites میرے freelance portfolio کی website بنائیں۔ اوپر واضح introduction، پھر تین services، منتخب projects، client testimonials کے placeholders، کام کا طریقہ اور contact form شامل کریں۔ زبان سادہ English رکھیں، design صاف ہو اور mobile پر تیزی سے سمجھ آئے۔ میری approval کے بغیر کوئی فرضی client، result یا testimonial شامل نہ کریں۔

### کمیونٹی event dashboard

> @Sites ہماری community workshop کے لیے website بنائیں۔ event details، agenda، speakers، registration form، volunteer tasks اور organizer dashboard شامل کریں۔ public page پر صرف ضروری معلومات دکھائیں؛ registrations اور اندرونی tasks منتخب organizers تک محدود رکھیں۔

## Public کرنے سے پہلے آخری جانچ کیا ہے؟

- title، نام، تاریخ، قیمت اور رابطہ درست ہیں؟
- تصاویر استعمال کرنے کی اجازت موجود ہے؟
- form واقعی submit ہو رہا ہے اور response صحیح جگہ جا رہا ہے؟
- mobile پر headline، menu اور buttons صاف نظر آتے ہیں؟
- private information public page پر تو نہیں؟
- Share option مطلوبہ audience تک ہی محدود ہے؟
- site پر کوئی فرضی claim، testimonial یا number تو شامل نہیں؟

ChatGPT site بنانے اور host کرنے کا کام سنبھال سکتا ہے، لیکن آپ ہی editor اور owner رہتے ہیں۔ درست brief دیں، چھوٹی تبدیلیاں ایک ایک کرکے کرائیں اور public link صرف آخری review کے بعد جاری کریں۔

## Sites option نظر نہ آئے تو؟

ستمبر 2026 تک Sites public beta میں ہے۔ OpenAI کے مطابق یہ Plus، Pro، Business، Enterprise اور Edu plans میں دستیاب ہے، لیکن plan-specific limits اور workspace permissions لاگو ہوتی ہیں۔ feature نظر نہ آئے تو اپنے ChatGPT account میں **More → Sites** دیکھیں؛ Business، Enterprise یا Edu workspace میں admin settings بھی access محدود کر سکتی ہیں۔
