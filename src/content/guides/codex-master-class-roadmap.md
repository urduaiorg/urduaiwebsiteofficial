اگر آپ کوڈیکس پہلی بار سیکھ رہے ہیں تو سب سے بڑی مشکل کوڈنگ نہیں ہوتی، بلکہ یہ ہوتی ہے کہ **شروع کہاں سے کریں**۔ اسی لیے یہ روڈ میپ گائیڈ بنائی گئی ہے تاکہ ابتدائی سیکھنے والے کو پوری سیریز ایک واضح ترتیب میں ملے۔

![کوڈیکس روڈ میپ گائیڈ cover](/images/guides/codex-guide-series/codex-roadmap-challenge.png)

## یہ روڈ میپ کس کے لیے ہے؟

یہ گائیڈ خاص طور پر ان لوگوں کے لیے ہے جو:

- تکنیکی پس منظر نہیں رکھتے
- اردو میں سیکھنا چاہتے ہیں
- کوڈیکس سے واقعی عملی نتیجہ بنانا چاہتے ہیں
- دستاویزات، ویب سائٹس، ایپس اور فری لانسنگ تک جانا چاہتے ہیں

اگر آپ کا مقصد صرف "کوڈیکس کیا ہے" جاننا نہیں بلکہ اسے استعمال کرنا ہے، تو یہی صحیح آغاز کا راستہ ہے۔

## کوڈیکس سیکھنے کی بہترین ابتدائی ترتیب

نیچے وہ ترتیب دی جا رہی ہے جو confusion کم کرتی ہے اور learning کو action میں بدلتی ہے۔

### 1. پہلے سمجھیں کوڈیکس کیا ہے

اس میں آپ یہ سمجھتے ہیں:

- کوڈیکس اور عام chat tool میں فرق
- کوڈیکس سے کیا عملی کام ہو سکتے ہیں
- ابتدائی صارفین کے لیے اس کی اصل value کیا ہے

### 2. پھر اس کے بنیادی الفاظ سمجھیں

- پلگ اِن

- ورک اسپیس

سب سے پہلے دستاویز اور سلائیڈز بنوانا بہتر رہتا ہے کیونکہ اس میں technical risk کم ہوتا ہے۔

- پریزنٹیشن یعنی presentation

## ابتدائی صارفین کے لیے سیکھنے کا اصول

کوڈیکس کے ساتھ ایک اہم اصول یاد رکھیں:

- پہلے سمجھیں
- پھر ایک چھوٹی چیز بنائیں
- پھر اسے improve کریں
- پھر save کریں
- پھر live کریں

یعنی learning ہمیشہ action کے ساتھ جڑی ہونی چاہیے۔

## اس سیریز کو پڑھتے وقت کیا مشق کریں؟

ہر گائیڈ کے بعد کم از کم ایک عملی نتیجہ بنائیں:

- ایک دستاویز
- ایک سلائیڈ outline
- ایک ویب پیج
- ایک ایپ idea
- ایک گٹ ہب repository
- ایک live link

اگر آپ صرف پڑھتے رہے اور کچھ بنایا نہیں، تو کوڈیکس سیکھنے کی رفتار بہت کم ہو جائے گی۔
