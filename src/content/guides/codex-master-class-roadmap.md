اگر آپ Codex پہلی بار سیکھ رہے ہیں تو سب سے بڑی مشکل coding نہیں ہوتی، بلکہ یہ ہوتی ہے کہ **شروع کہاں سے کریں**۔ اسی لیے یہ roadmap guide بنائی گئی ہے تاکہ beginner learner کو پوری series ایک واضح ترتیب میں ملے۔

## یہ roadmap کس کے لیے ہے؟

یہ guide خاص طور پر ان لوگوں کے لیے ہے جو:

- non-technical ہیں
- Urdu میں سیکھنا چاہتے ہیں
- Codex سے واقعی practical output بنانا چاہتے ہیں
- documents، websites، apps اور freelancing تک جانا چاہتے ہیں

اگر آپ کا مقصد صرف "Codex کیا ہے" جاننا نہیں بلکہ اسے استعمال کرنا ہے، تو یہی صحیح entry point ہے۔

Codex کے ساتھ ایک اہم اصول یاد رکھیں:

- پہلے سمجھیں
- پھر ایک چھوٹی چیز بنائیں
- پھر اسے improve کریں
- پھر save کریں
- پھر live کریں

یعنی learning ہمیشہ action کے ساتھ جڑی ہونی چاہیے۔
