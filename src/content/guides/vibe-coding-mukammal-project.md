12 گائیڈز میں ہم نے سب الگ الگ سیکھا — فرنٹ اینڈ، بیک اینڈ، لاگ ان، ڈیٹابیس، ہوسٹنگ، ادائیگی۔ اب وقت ہے سب کچھ ملا کر ایک مکمل ایپ بنانے کا۔

آج ہم شروع سے آخر تک ایک **اپائنٹمنٹ بکنگ ایپ** بنائیں گے — جو اصلی صارفین استعمال کر سکیں اور آپ اس سے پیسے کما سکیں۔

## ہم کیا بنائیں گے؟

**ایپ:** اپائنٹمنٹ بکنگ سسٹم — جیسے ڈاکٹر، ٹیوٹر، یا سیلون کے لیے

**فیچرز:**

- صارف گوگل سے لاگ ان کرے
- دستیاب ٹائم سلاٹس دیکھے
- اپائنٹمنٹ بُک کرے
- اپنی بکنگز دیکھے اور منسوخ کرے
- ایڈمن اپنے سلاٹس سیٹ کرے

**ٹیکنالوجی:**

- Google AI Studio (Build Mode) — ایپ بنانے کے لیے
- Firebase — ڈیٹابیس اور لاگ ان
- Vercel — مفت ہوسٹنگ
- LemonSqueezy — ادائیگی (اختیاری)

## مرحلہ 1 — بنیادی ایپ بنائیں (30-45 منٹ)

Google AI Studio کا Build Mode کھولیں اور لکھیں:

"ایک اپائنٹمنٹ بکنگ ایپ بنا دو جس میں:

- صارف گوگل سے لاگ ان کرے
- ایک کیلنڈر نظر آئے جس میں دستیاب ٹائم سلاٹس ہوں
- صارف اپنا پسندیدہ سلاٹ منتخب کر کے بُک کرے
- بُک شدہ سلاٹ دوسروں کو نظر نہ آئے
- صارف اپنی بکنگز کی فہرست دیکھ سکے
- رنگ نیلے اور سفید ہوں
- موبائل پر اچھی دکھے
- Firebase استعمال کرو"

AI ایپ بنائے گا — لاگ ان، ڈیٹابیس، UI سب خود سیٹ اپ کرے گا۔

## مرحلہ 2 — ایڈمن پینل شامل کریں (15-20 منٹ)

اب AI سے کہیں:

"اس ایپ میں ایڈمن پینل شامل کرو:

- ایک مخصوص ای میل والا صارف ایڈمن ہو
- ایڈمن نئے ٹائم سلاٹس بنا سکے — تاریخ اور وقت سیٹ کرے
- ایڈمن تمام بکنگز کی فہرست دیکھ سکے
- ایڈمن کوئی بھی بکنگ منسوخ کر سکے
- عام صارف ایڈمن پینل نہ دیکھ سکے"

## مرحلہ 3 — ڈیزائن بہتر کریں (10-15 منٹ)

"ایپ کا ڈیزائن بہتر کرو:

- بکنگ کارڈز میں سلاٹ کا وقت، تاریخ اور حیثیت واضح ہو
- بکنگ ہو جائے تو سبز رنگ کا تصدیقی پیغام دکھے
- خالی حالت میں (کوئی بکنگ نہیں) ایک اچھا پیغام دکھے
- لوڈنگ کے دوران لوڈنگ اینیمیشن دکھے"

## مرحلہ 4 — ٹیسٹنگ (15-20 منٹ)

ایپ بن گئی — اب ٹیسٹ کریں:

**بنیادی ٹیسٹ:**

- گوگل سے لاگ ان کریں — کام کرتا ہے؟
- سلاٹ بُک کریں — محفوظ ہوتا ہے؟
- صفحہ ریفریش کریں — بکنگ نظر آتی ہے؟
- بکنگ منسوخ کریں — ہٹ جاتی ہے؟

**ایج کیسز:**

- ایک ہی سلاٹ دو بار بُک کریں — کیا ہوتا ہے؟
- لاگ آؤٹ کر کے دوبارہ لاگ ان کریں — بکنگ برقرار ہے؟
- موبائل پر کھولیں — سب ٹھیک دکھتا ہے؟

**کنسول چیک:** F12 دبائیں — کوئی سرخ ایرر تو نہیں؟

## مرحلہ 5 — GitHub پر محفوظ کریں (5 منٹ)

AI Studio سے کوڈ ایکسپورٹ کریں اور GitHub ریپو میں ڈالیں — جیسا ہم نے [GitHub گائیڈ](/guides/vibe-coding-github-version-control/) میں سیکھا۔

## مرحلہ 6 — لائیو کریں (5-10 منٹ)

**Vercel سے:**

1. vercel.com پر GitHub سے سائن ان
2. Import Project → اپنی ریپو منتخب کریں
3. Deploy — ایک منٹ میں لائیو
4. لنک ملے گا: your-app.vercel.app

ایپ اب دنیا میں کوئی بھی استعمال کر سکتا ہے۔

## مرحلہ 7 — ادائیگی لگائیں (اختیاری)

اگر ایپ سے پیسے کمانا چاہتے ہیں:

AI سے کہیں:
"اس ایپ میں دو پلان بنا دو:

- مفت: ماہانہ 3 بکنگز
- پرو: لامحدود بکنگز — ماہانہ 5 ڈالر
- LemonSqueezy سے ادائیگی لگا دو"

## مکمل ایپ — خلاصہ

آپ نے ابھی ایک مکمل SaaS ایپ بنائی:

| حصہ | کیا استعمال کیا | خرچہ |
| --- | --- | --- |
| فرنٹ اینڈ | Google AI Studio | مفت |
| لاگ ان | Firebase Auth | مفت |
| ڈیٹابیس | Firebase Firestore | مفت |
| ہوسٹنگ | Vercel | مفت |
| کوڈ محفوظ | GitHub | مفت |
| ادائیگی | LemonSqueezy | فروخت پر فیس |

**کل خرچہ: صفر** (جب تک ادائیگی نہ لیں)

## اس ایپ کو کیسے بڑھائیں؟

یہ بکنگ ایپ مختلف کاموں کے لیے استعمال ہو سکتی ہے:

- **ڈاکٹر کا کلینک** — مریض آن لائن اپائنٹمنٹ لیں
- **ٹیوشن ٹیچر** — طلبہ کلاس بُک کریں
- **سیلون** — گاہک اپنا وقت منتخب کریں
- **فری لانسر** — کلائنٹ میٹنگ بُک کریں
- **کھیل کا میدان** — گراؤنڈ بکنگ

ہر مقصد کے لیے AI سے کہیں فیچرز بدل دے — بنیادی ڈھانچہ وہی رہتا ہے۔
