پچھلی گائیڈ میں ہم نے سمجھا کہ وائب کوڈنگ کیا ہے۔ اب سب سے اہم سوال — کون سے ٹولز استعمال ہوتے ہیں اور آپ کے لیے کون سا بہترین ہے؟

آسان الفاظ میں: یہ ٹولز وہ AI اسسٹنٹ ہیں جو آپ کی بات سن کر کوڈ لکھتے ہیں۔ ہر ٹول کا اپنا انداز ہے — کوئی نئے لوگوں کے لیے آسان ہے، کوئی بڑے پروجیکٹس کے لیے طاقتور۔

## ٹولز کی دو قسمیں

پہلے یہ سمجھ لیں کہ وائب کوڈنگ ٹولز دو قسم کے ہوتے ہیں:

**1. براؤزر والے ٹولز** — سب کچھ ویب سائٹ پر ہوتا ہے، کچھ ڈاؤن لوڈ نہیں کرنا

- Replit، Lovable، Bolt، Google AI Studio، v0

**2. ڈیسک ٹاپ والے ٹولز** — لیپ ٹاپ پر انسٹال ہوتے ہیں، زیادہ طاقتور

- Cursor، Claude Code، GitHub Copilot، Windsurf

**شروع کرنے والوں کے لیے:** براؤزر والے ٹولز سے شروع کریں — آسان ہیں اور فوری نتیجہ ملتا ہے۔

## Replit — سب سے آسان شروعات

Replit (ری پلٹ) ایک آن لائن پلیٹ فارم ہے جہاں آپ AI سے بات کر کے ایپس بنا سکتے ہیں۔

**کیا اچھا ہے:**

- براؤزر میں چلتا ہے — کچھ انسٹال نہیں کرنا
- AI Agent آپ کی بات سن کر پورا پروجیکٹ بنا دیتا ہے
- فوری طور پر لائیو لنک ملتا ہے جو دوسروں کو دکھا سکتے ہیں
- موبائل پر بھی استعمال ہو سکتا ہے

**کس کے لیے بہتر:** بالکل نئے لوگ جو پہلی بار کچھ بنانا چاہتے ہیں

**مفت پلان:** ہاں — شروع کرنے کے لیے کافی

## Lovable — خوبصورت ویب سائٹس منٹوں میں

Lovable (لوایبل) خاص طور پر ویب سائٹس اور لینڈنگ پیجز بنانے کے لیے ہے۔

**کیا اچھا ہے:**

- آپ بتاتے ہیں "مجھے ایک پروڈکٹ کا لینڈنگ پیج چاہیے" — وہ خوبصورت ڈیزائن بنا دیتا ہے
- ڈیزائن کا معیار بہت اچھا ہوتا ہے
- GitHub سے جڑ جاتا ہے
- Supabase (ڈیٹابیس) سے بھی جڑ سکتا ہے

**کس کے لیے بہتر:** جنہیں خوبصورت ویب سائٹ یا لینڈنگ پیج فوری چاہیے

**مفت پلان:** محدود — لیکن پہلے پروجیکٹ کے لیے کافی

## Bolt — تیز رفتار پروٹو ٹائپنگ

Bolt (بولٹ) Stackblitz کا AI ٹول ہے جو براؤزر میں مکمل ایپس بناتا ہے۔

**کیا اچھا ہے:**

- بہت تیز — چند منٹوں میں پورا پروجیکٹ
- React، Next.js جیسے فریم ورکس سپورٹ کرتا ہے
- براؤزر میں ہی سب ہوتا ہے
- ایکسپورٹ کر کے کہیں بھی ڈیپلائے کر سکتے ہیں

**کس کے لیے بہتر:** جنہیں تیزی سے آئیڈیا ٹیسٹ کرنا ہو

**مفت پلان:** ہاں — روزانہ محدود ٹوکنز

## Google AI Studio — مکمل مفت وائب کوڈنگ پلیٹ فارم

Google AI Studio اب صرف AI چیٹ نہیں رہا — اس میں Build Mode ہے جو مکمل وائب کوڈنگ پلیٹ فارم ہے۔ Antigravity ایجنٹ آپ کی بات سن کر فل سٹیک ایپس بناتا ہے۔

**کیا اچھا ہے:**

- بالکل مفت — کوئی کریڈٹ کارڈ نہیں چاہیے
- Build Mode میں بتائیں کیا چاہیے — پوری ایپ بن جائے
- فرنٹ اینڈ اور بیک اینڈ دونوں بناتا ہے
- Firebase بلٹ ان — ڈیٹابیس اور لاگ ان سسٹم خودکار
- لائیو پریویو — فوری دیکھیں کیا بن رہا ہے
- React، Angular، Next.js سپورٹ
- سیدھا ڈیپلائے (پبلش) کر سکتے ہیں
- پاکستان میں بغیر VPN کام کرتا ہے

**کس کے لیے بہتر:** ہر کسی کے لیے — نئے لوگوں سے لے کر سنجیدہ بلڈرز تک

**مفت پلان:** ہاں — مکمل مفت

## Cursor — پروفیشنل وائب کوڈنگ

Cursor (کرسر) ایک ڈیسک ٹاپ کوڈ ایڈیٹر ہے — VS Code جیسا دکھتا ہے لیکن اس میں AI بلٹ ان ہے۔

**کیا اچھا ہے:**

- سب سے طاقتور وائب کوڈنگ ٹول
- پورے پروجیکٹ کو سمجھتا ہے — صرف ایک فائل نہیں
- Tab دبائیں اور AI اگلا کوڈ خود لکھ دے
- چیٹ میں بتائیں "یہ بگ ٹھیک کرو" — وہ خود ڈھونڈ کر ٹھیک کرے

**کس کے لیے بہتر:** تھوڑا سیکھنے کے بعد — جب بڑے پروجیکٹس بنانے لگیں

**مفت پلان:** ہاں — محدود لیکن شروع کے لیے کافی

## Claude Code — Anthropic کا کوڈنگ ٹول

Claude Code (کلاڈ کوڈ) ٹرمینل میں چلتا ہے اور بڑے پروجیکٹس میں مدد کرتا ہے۔

**کیا اچھا ہے:**

- پورے کوڈ بیس کو سمجھتا ہے
- فائلز خود بنا سکتا ہے، ایڈٹ کر سکتا ہے
- GitHub سے براہ راست کام کرتا ہے
- پیچیدہ کام جو کئی فائلز پر ہوں — وہ خود سنبھالتا ہے

**کس کے لیے بہتر:** درمیانے سے بڑے پروجیکٹس — جب Cursor سے آگے بڑھیں

**مفت پلان:** نہیں — لیکن Anthropic API کی قیمت مناسب ہے

## v0 — Vercel کا UI بلڈر

v0 (وی زیرو) خاص طور پر یوزر انٹرفیس (UI) بنانے کے لیے ہے۔

**کیا اچھا ہے:**

- "مجھے ایک ڈیش بورڈ چاہیے" کہیں — وہ خوبصورت UI بنا دے
- React کمپوننٹ کوڈ دیتا ہے
- ڈیزائن کا معیار بہت اونچا ہے

**کس کے لیے بہتر:** جنہیں صرف UI ڈیزائن چاہیے

## GitHub Copilot — مائیکروسافٹ کا AI اسسٹنٹ

GitHub Copilot (گٹ ہب کو پائلٹ) VS Code میں انسٹال ہوتا ہے اور کوڈ لکھتے وقت تجاویز دیتا ہے۔

**کیا اچھا ہے:**

- لکھتے لکھتے اگلی لائن تجویز کرتا ہے
- تقریباً ہر پروگرامنگ زبان سپورٹ کرتا ہے
- چیٹ میں سوال بھی پوچھ سکتے ہیں

**کس کے لیے بہتر:** جو پہلے سے VS Code استعمال کرتے ہیں

**مفت پلان:** طلبہ کے لیے مفت — باقی ماہانہ فیس

## Windsurf — نیا لیکن طاقتور

Windsurf (ونڈ سرف) Cursor کا مقابلہ کرنے والا نیا ایڈیٹر ہے۔

**کیا اچھا ہے:**

- Cursor جیسی خصوصیات لیکن کچھ معاملات میں تیز
- مفت پلان Cursor سے زیادہ فراخ دل
- AI فلو فیچر — کئی کام خودکار طریقے سے کرتا ہے

**کس کے لیے بہتر:** Cursor کا متبادل چاہنے والے

## تو شروع کہاں سے کریں؟

آپ کی ضرورت کے حساب سے:

**بالکل نئے ہیں:**
→ Google AI Studio سے شروع کریں — مکمل مفت، پاکستان میں کام کرتا ہے، Build Mode میں AI سے کہیں "ایک ٹو ڈو ایپ بنا دو"

**خوبصورت ویب سائٹ چاہیے:**
→ Lovable یا Bolt آزمائیں

**مفت میں فل سٹیک ایپ بنانی ہے:**
→ Google AI Studio — فرنٹ اینڈ، بیک اینڈ، ڈیٹابیس، ڈیپلائمنٹ سب ایک جگہ

**سنجیدگی سے سیکھنا ہے:**
→ Cursor انسٹال کریں — اس سیریز میں ہم آگے اسی پر زیادہ کام کریں گے
