آپ نے ایپ بنا لی — فرنٹ اینڈ، بیک اینڈ، لاگ ان سب تیار۔ اب سب سے بڑا سوال: اسے دنیا کو کیسے دکھائیں؟ کیا ڈومین خریدنا ضروری ہے؟ سرور کا خرچہ کتنا آئے گا؟

جواب: **ایک پیسہ نہیں لگتا۔**

2026 میں کئی پلیٹ فارمز مکمل مفت ہوسٹنگ دیتے ہیں — مفت ایڈریس کے ساتھ۔ آئیں سب جانتے ہیں۔

## مفت ہوسٹنگ کیسے کام کرتی ہے؟

جب آپ ویب سائٹ بناتے ہیں تو وہ آپ کے کمپیوٹر پر ہوتی ہے — صرف آپ دیکھ سکتے ہیں۔ ہوسٹنگ کا مطلب ہے اسے کسی سرور پر رکھنا تاکہ دنیا میں کوئی بھی اپنے فون یا کمپیوٹر سے دیکھ سکے۔

سوچیں آپ نے گھر میں کھانا بنایا — صرف آپ کھا سکتے ہیں۔ لیکن اگر ریسٹورنٹ میں رکھ دیں تو سب آ کر کھا سکتے ہیں۔ ہوسٹنگ = آپ کی ویب سائٹ کا ریسٹورنٹ۔

مفت ہوسٹنگ پلیٹ فارمز آپ کو:

- مفت سرور دیتے ہیں
- مفت ایڈریس دیتے ہیں (جیسے yourname.github.io)
- خودکار اپڈیٹ — GitHub پر Push کریں اور ویب سائٹ خود بدل جائے

## 1. GitHub Pages — سب سے آسان شروعات

GitHub Pages آپ کی GitHub ریپو کو مفت ویب سائٹ بنا دیتا ہے۔

**ایڈریس ملتا ہے:** yourname.github.io/project-name

**کیا بنا سکتے ہیں:**

- پورٹ فولیو ویب سائٹ
- بلاگ
- لینڈنگ پیج
- ڈاکومینٹیشن سائٹ

**حدود:**

- صرف سٹیٹک سائٹس (HTML، CSS، JS) — بیک اینڈ نہیں چلتا
- 1 GB سٹوریج
- ماہانہ 100 GB بینڈوڈتھ

**کیسے شروع کریں:**

1. GitHub پر ریپو بنائیں (یہ ہم [GitHub گائیڈ](/guides/vibe-coding-github-version-control/) میں سیکھ چکے)
2. Settings → Pages پر جائیں
3. Source میں main برانچ منتخب کریں
4. Save کریں — چند منٹوں میں ویب سائٹ لائیو

**بہترین ہے اگر:** سادہ ویب سائٹ، پورٹ فولیو، یا پروجیکٹ شوکیس بنانا ہے

## 2. Cloudflare Pages — لامحدود بینڈوڈتھ مفت

Cloudflare Pages سب سے فراخ دل مفت پلان دیتا ہے — **لامحدود بینڈوڈتھ۔** اگر آپ کی سائٹ وائرل ہو جائے تو بھی ایک پیسہ نہیں لگے گا۔

**ایڈریس ملتا ہے:** project-name.pages.dev

**کیا بنا سکتے ہیں:**

- سٹیٹک ویب سائٹس
- React، Next.js، Vue ایپس
- Cloudflare Workers سے بیک اینڈ بھی (محدود)

**حدود:**

- مفت پلان میں 500 بلڈز ماہانہ
- 1 بلڈ ایک وقت میں
- لیکن بینڈوڈتھ لامحدود — سب سے بڑا فائدہ

**کیسے شروع کریں:**

1. Cloudflare اکاؤنٹ بنائیں (مفت)
2. Pages سکشن میں جائیں
3. GitHub ریپو سے جوڑیں
4. ہر Push پر خودکار ڈیپلائے

**بہترین ہے اگر:** ایپ پر زیادہ ٹریفک آنے کا امکان ہے اور بینڈوڈتھ کی فکر نہیں چاہتے

## 3. Vercel — Next.js ایپس کا گھر

Vercel (ورسل) خاص طور پر React اور Next.js ایپس کے لیے بنایا گیا ہے۔ زیادہ تر وائب کوڈنگ ٹولز React ایپس بناتے ہیں — تو Vercel قدرتی انتخاب ہے۔

**ایڈریس ملتا ہے:** project-name.vercel.app

**کیا بنا سکتے ہیں:**

- React / Next.js ایپس
- سرور لیس فنکشنز (بیک اینڈ لاجک)
- API Routes

**مفت پلان:**

- 100 GB بینڈوڈتھ ماہانہ
- سرور لیس فنکشنز شامل
- خودکار HTTPS (محفوظ کنکشن)

**کیسے شروع کریں:**

1. vercel.com پر GitHub سے سائن اپ
2. "Import Project" سے GitHub ریپو منتخب کریں
3. Deploy پر کلک کریں — ایک منٹ میں لائیو

**بہترین ہے اگر:** React یا Next.js ایپ بنائی ہے (Bolt، v0، Lovable سے بنائی ہوئی ایپس)

## 4. Netlify — فارمز اور فنکشنز مفت

Netlify (نیٹلیفائی) Vercel جیسا ہی ہے لیکن اس میں فارم ہینڈلنگ مفت ملتی ہے — رابطہ فارم سے آنے والے پیغامات خود محفوظ ہوتے ہیں۔

**ایڈریس ملتا ہے:** project-name.netlify.app

**مفت پلان:**

- 100 GB بینڈوڈتھ ماہانہ
- فارم سبمشنز (100 ماہانہ مفت)
- سرور لیس فنکشنز (125,000 کالز مفت)
- خودکار HTTPS

**بہترین ہے اگر:** ویب سائٹ میں رابطہ فارم ہے اور بیک اینڈ نہیں بنانا چاہتے

## 5. Google Antigravity — AI Studio سے ایک کلک ڈیپلائے

اگر آپ Google AI Studio کے Build Mode میں ایپ بنا رہے ہیں تو سب سے آسان — ایک بٹن دبائیں اور ایپ لائیو۔

**کیسے کام کرتا ہے:**

- AI Studio میں ایپ بنائیں
- Deploy بٹن دبائیں
- Google Antigravity پر لائیو ہو جائے
- Google Cloud Run پر بھی ڈیپلائے کر سکتے ہیں

**مفت پلان:** ریٹ لمیٹڈ مفت رسائی — چھوٹی ایپس کے لیے کافی

**بہترین ہے اگر:** Google AI Studio میں ایپ بنائی ہے اور فوری لائیو کرنا ہے

## موازنہ — کون سا کب؟

| پلیٹ فارم | بہترین استعمال | مفت بینڈوڈتھ | بیک اینڈ | آسانی |
| --- | --- | --- | --- | --- |
| GitHub Pages | پورٹ فولیو، بلاگ | 100 GB | نہیں | بہت آسان |
| Cloudflare Pages | ہائی ٹریفک سائٹس | لامحدود | محدود | آسان |
| Vercel | React/Next.js ایپس | 100 GB | ہاں | آسان |

| Antigravity | AI Studio ایپس | محدود | ہاں | سب سے آسان |

## عملی مشق — اپنی ایپ لائیو کریں

پچھلی گائیڈز میں جو نوٹس ایپ بنائی تھی — آئیں اسے لائیو کریں:

**طریقہ 1 — Google AI Studio سے (سب سے آسان):**
اگر AI Studio میں بنائی ہے تو Deploy بٹن دبائیں — بس، لائیو

**طریقہ 2 — Vercel سے:**

1. ایپ کا کوڈ GitHub ریپو میں Push کریں
2. vercel.com پر جائیں → Import Project
3. GitHub ریپو منتخب کریں → Deploy
4. ایک منٹ میں لائیو — لنک شیئر کریں

**طریقہ 3 — سادہ HTML سائٹ GitHub Pages سے:**

1. GitHub ریپو میں index.html فائل ہو
2. Settings → Pages → Source: main
3. Save — چند منٹوں میں لائیو

## کسٹم ڈومین — بعد میں جب چاہیں

ابھی مفت ایڈریس سے شروع کریں (yourapp.vercel.app)۔ جب ایپ کامیاب ہو اور آپ پیشہ ورانہ نام چاہیں (myapp.com) — تب ڈومین خریدیں:

- ڈومین سالانہ 2,000 سے 5,000 روپے میں ملتا ہے
- Namecheap، Cloudflare، GoDaddy سے خریدیں
- کسٹم ڈومین Vercel، Netlify، Cloudflare Pages سب سے مفت جڑ جاتا ہے

لیکن **شروع میں یہ ضروری نہیں** — پہلے بنائیں، لوگوں کو دکھائیں، فیڈبیک لیں — ڈومین بعد میں۔

## اہم اصطلاحات

- **ہوسٹنگ** — ویب سائٹ کو آن لائن رکھنا تاکہ سب دیکھ سکیں
- **ڈیپلائے** — ایپ کو سرور پر لگانا (لائیو کرنا)
- **ڈومین** — ویب سائٹ کا نام (مثلاً urduai.org)
- **بینڈوڈتھ** — کتنا ڈیٹا ٹرانسفر ہو سکتا ہے (جتنے زیادہ وزیٹرز، اتنا زیادہ)
- **SSL / HTTPS** — محفوظ کنکشن (تالے والا نشان)
- **CI/CD** — خودکار ڈیپلائمنٹ — Push کریں اور سائٹ خود اپڈیٹ ہو
- **سٹیٹک سائٹ** — صرف HTML/CSS/JS — سرور کی ضرورت نہیں
- **سرور لیس** — بیک اینڈ کوڈ چلے لیکن سرور آپ نہ سنبھالیں
